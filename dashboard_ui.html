What is Claude Code?

Claude Code is an agentic coding tool that lives in your terminal, understands your codebase, and helps you code faster by executing routine tasks, explaining complex code, and handling git workflows — all through natural language commands.

It serves as an agentic harness around Claude: it provides the tools, context management, and execution environment that turn a language model into a capable coding agent.

Core Philosophy

The agentic loop is powered by two fundamental components:

  1. Models that reason about your code
  2. Tools that act on the environment

System Architecture: Six-Layer Stack

Layer Component Purpose
1. UI/Interfaces CLI, VS Code, JetBrains, Web, SDK Entry points for user interaction
2. Agent Loop query.ts — async generator Heartbeat: stream → tool call → execute → loop
3. Tools ~40 tools (51K LOC, 184 files) File ops, bash, search, web, MCP, subagents
4. Services 54K LOC, 130 files API adapter, context compaction, memory, telemetry
5. State Mutable singleton + reactive store Session config, messages, approvals
